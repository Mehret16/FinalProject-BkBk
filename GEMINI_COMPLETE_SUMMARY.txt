🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

1️⃣  GET API KEY
   Go to: https://aistudio.google.com/app/apikeys
   Click: "Get API Key"
   Copy: Your key

2️⃣  ADD TO .env
   GEMINI_API_KEY=your_key_here
   GEMINI_MODEL=gemini-pro
   GEMINI_TEMPERATURE=0.7
   GEMINI_MAX_TOKENS=1024

3️⃣  INSTALL & RUN
   cd /backend
   npm install
   npm run dev

4️⃣  TEST IT
   curl -X POST http://localhost:5000/api/chat/message \
     -H "Authorization: Bearer TOKEN" \
     -d '{"sessionId": 1, "messageText": "I feel anxious"}'

✨ Done! You now have AI-powered mental health support!

🔗 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════

POST /api/chat/message
├─ Input: sessionId, messageText, language
├─ Process: Send through Gemini AI
└─ Output: Patient message + Bot response + Classification + Alert (if HIGH risk)

GET /api/chat/crisis-analysis/:sessionId
├─ Analyzes conversation for crisis indicators
├─ Returns: Risk percentage, risk level, crisis indicators
└─ Used by: Therapist dashboard, admin alerts

GET /api/chat/analytics/:sessionId
├─ Full session analysis
├─ Returns: Message stats, classifications, duration
└─ Used by: Therapist reports, admin analytics

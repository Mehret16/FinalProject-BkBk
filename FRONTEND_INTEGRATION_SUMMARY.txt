================================================================================
                         CORE API ENDPOINTS
================================================================================

AUTHENTICATION:
  POST   /auth/register              - Create account
  POST   /auth/login                 - Login (returns tokens)
  GET    /auth/me                    - Current user info

CHAT:
  POST   /chat/session/create        - Start new chat
  POST   /chat/message               - Send message (gets AI response)
  GET    /chat/history/:id           - Get chat history
  GET    /chat/sessions              - Get all patient sessions
  POST   /chat/close/:id             - Close session

REFERRALS (Key Feature):
  POST   /referrals/create           - Patient creates referral
  GET    /referrals/my-referrals     - Get patient's referrals
  POST   /referrals/access           - Therapist access patient data
  POST   /referrals/therapist        - Get referrals for therapist

USERS:
  GET    /users/profile              - Get user profile
  PUT    /users/profile              - Update profile
  GET    /users/therapist/:id/info   - Get therapist info

RESOURCES (Public):
  GET    /resources                  - Get mental health resources
  GET    /resources/categories       - Get categories

================================================================================
                        REFERRAL WORKFLOW (KEY)
================================================================================

1. Patient initiates:
   POST /referrals/create
   - Provide: therapistId, reason, urgency

2. Backend automatically:
   - Creates referral in database
   - Generates unique access token (valid 7 days)
   - Sends email to therapist with link containing token

3. Therapist receives email:
   - Email contains secure link with token
   - Link: https://frontend.com/therapist/referral?access_token=JWT

4. Therapist clicks link:
   - Frontend extracts token from URL
   - Calls: POST /referrals/access with token

5. Therapist gets full access:
   {
     "patient": { full profile },
     "chatSessions": [ all sessions ],
     "messages": [ all messages ],
     "referralDetails": { ... }
   }

This ensures secure, time-limited access!

REFERRAL (THERAPIST):

const data = await accessPatientData(tokenFromEmail);
// Now have: patient profile, all messages, sessions

================================================================================
                        TROUBLESHOOTING
================================================================================

Backend won't start?
  → Check MySQL is running
  → Check port 5000 is free
  → See SETUP_COMPLETE.md

Frontend can't connect?
  → Check backend URL in .env.local
  → Check CORS (already configured)
  → See CONNECT_FRONTEND_NOW.md

Token expired?
  → Auto-handled, user redirected to login
  → See useAuth hook

Referral email not sending?
  → Check SETUP_EMAIL.md
  → Verify Gmail app password
  → Check email logs in backend

Gemini AI not responding?
  → Check GEMINI_API_KEY in .env
  → See GEMINI_AI_SETUP.md
  → Test with /health endpoint
